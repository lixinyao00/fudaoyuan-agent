# 辅导员AI问答机器人 - 前端

基于 Vue 3 + Vite 构建的前端应用。

## 技术栈

- Vue 3
- Vite
- CSS

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 目录结构

```
src/
├── pages/          # 页面组件
│   ├── Chat.vue    # 问答页面
│   ├── Admin.vue   # 管理后台
│   └── Login.vue   # 登录页面
├── services/       # API 服务
│   └── api.js      # 接口封装
├── App.vue         # 根组件
└── main.js         # 入口文件
```

## 访问地址

- 开发模式: http://localhost:5173
- 生产模式: http://localhost:8080 (由后端提供)
